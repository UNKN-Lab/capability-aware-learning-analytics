# Contributing

Thank you for your interest in the project.

Before submitting a change:

1. Keep credentials, private datasets, student records, and raw model logs out
   of commits.
2. Add or update tests for behavior changes.
3. Run the Frontend, Backend, and AI service verification commands documented
   in `README.md`.
4. Keep public fixtures synthetic, anonymized, or clearly redistributable under
   their source license.
5. Explain the motivation, scope, and verification evidence in the pull
   request.

By contributing, you confirm that you have the right to submit the material.
